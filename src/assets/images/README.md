# Images

Put photos and screenshots here (JPG, PNG or WebP, at least 1600px wide where possible),
then pass them to the `<Figure>` component. Astro converts them to AVIF/WebP and serves
the right size for each screen at build time.

Never use gambling imagery (chips, cards, slot machines, odds). See the README tone rules.
