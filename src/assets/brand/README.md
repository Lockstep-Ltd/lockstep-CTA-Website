# Brand artwork

These are Lockstep's own logo files, taken from the original lockstep.uk site.
**Do not redraw, recolour or modify them.** Only resizing is allowed.

| File | What it is |
|---|---|
| `lockstep-logo.png` | Full logo (padlock-and-steps mark + "Lockstep" wordmark). Original artwork, with the empty margin around it cropped off; the logo itself is unchanged. |
| `lockstep-icon.png` | The app icon (mark only, on cream). Used for the favicon, Apple touch icon and social sharing images. |
| `lock-steps.webp` | Lock-and-steps illustration from the old home page (first frame of the original animation, resized). |

The logo is dark green on a transparent background, so on dark green areas (e.g. the footer)
it sits on a cream tile rather than being recoloured.
